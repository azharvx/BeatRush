# BeatRush
A web-based rhythm game.

## Description
BeatRush is a dynamic, cross-platform musical rhythm game built from scratch using HTML, CSS, and vanilla JavaScript. Players hit notes descending down the screen to the beat of the music. It features full-column mobile touch support, PC keyboard controls (using the D, F, J, and K keys), dynamic lane sizing, and a balanced speed scaling progression system.

## Getting Started

### Dependencies
* Any modern web browser (Google Chrome, Mozilla Firefox, Apple Safari, Microsoft Edge).
* No additional installations, libraries, or specific OS versions are required.

### Installing
* Download the repository as a ZIP file or clone it to your local machine.
* Extract the files to a folder on your computer.

### Executing program
* Navigate to the folder where you extracted the project files.
* Double-click the `index.html` file to open it in your default web browser.
* Interact with the screen to begin the game.

## Help
**Common Issue: Music not playing**
Modern web browsers block audio from playing automatically. Ensure you click or tap anywhere on the game screen first to allow the audio context to start.
